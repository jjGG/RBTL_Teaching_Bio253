Architecture

The Ideal Omics Workspace Layout

📁 my_omics_project/
├── data/
├── counts_matrix.tsv (genes × samples)
├── sample_metadata.csv (conditions, batches)
└── gene_annotations.tsv (symbols, biotypes)
├── analysis_prompt.md ★ AI Instructions
├── scripts/ (AI writes code here)
├── results/ (volcano.png, pca.png, degs.csv)
├── report.qmd (Quarto / Rmd document)
└── .gitignore (Never commit raw GBs!)

1. Clean Separation of Data & Metadata

Never mix experimental design into the expression matrix. The AI needs a dedicated `sample_metadata.csv` to map sample IDs to treatment groups.

2. Provide Data Dictionaries

Include header notes or a markdown snippet describing column definitions (e.g. `Condition: WT vs KO`, `Batch: Replicate 1-3`).

3. Processed Tables over Raw Fastq/Raw MS

Do not point the agent to 50GB FASTQ or mzML files. Point it to quantified count matrices, peptide tables, or AnnData summaries.

💡 Teaching Goal: Emphasize that workspace organization is 80% of agentic success. When file paths, metadata columns, and inputs are tidy, the AI writes correct scripts on the first try with minimal hallucinated column names.
Prompt Engineering

Anatomy of an Effective Omics Agent Prompt

Prompt Specification Example

Task: Run differential expression on `data/counts_matrix.tsv` using sample conditions in `data/sample_metadata.csv` (Control vs Treatment).

Workflow:

1. Normalize using DESeq2 (or edgeR / limma-voom).

2. Generate PCA plot (PC1 vs PC2, colored by Condition, shaped by Batch) ➔ save to `results/pca.png`.

3. Extract DEGs: log2FC > 1.0, Benjamini-Hochberg FDR < 0.05.

4. Produce an interactive Volcano plot and Heatmap of top 50 genes.

Deliverable: Write all code into `scripts/analyze_degs.py` (or `.R`), run it in terminal, verify zero errors, and output an executive summary in `report.md`.

✓ Explicit input paths  •  ✓ Statistical thresholds  •  ✓ Output destinations

1. Explicit Statistical Cutoffs

Never say "find significant genes." State the exact FDR adjustment (padj < 0.05) and effect size (|log2FC| ≥ 1).

2. Batch Effect Awareness

Instruct the agent whether to include batch covariates in the design formula (design = ~ Batch + Condition).

3. Self-Verification Requirement

Add the instruction: "Execute the script via terminal. If a package is missing or code fails, fix the code and rerun until clean exit code 0."

4. Format of Deliverable

Require the agent to write clean, modular scripts plus a Quarto/Markdown report instead of just dumping stdout.

💡 Teaching Goal: Show students how fuzzy prompts lead to generic answers, while structured prompts produce ready-to-publish analysis pipelines.
Execution Cycle

What the Agent Does in the Workspace

01

Inspection

Agent reads file headers, shapes, and column names without loading full GBs into context.

head -n 5 counts.tsv
02

Code Authoring

Writes complete statistical scripts in R or Python (DESeq2, PyDESeq2, scanpy, protti).

write_to_file script.py
03

Terminal Run & Fix

Executes the code. If an index mismatch or NA issue appears, reads traceback and patches bug.

python3 scripts/run.py
04

Synthesis & Report

Generates figures, summarizes top pathways, writes markdown / HTML report with embedded graphs.

quarto render report.qmd
💡 The Key Pedagogical Difference: The student acts as the Principal Investigator / Reviewer. They verify the biological plausibility of the results, rather than debugging syntax typos.

Quality Control

4 Bioinformatic Pitfalls to Watch Out For

⚠️

1. The Unadjusted p-Value Trap

AI models sometimes default to raw p-values (p < 0.05) instead of multiple-testing adjusted values (FDR / Benjamini-Hochberg). Always prompt specifically for adjusted p-values!

⚠️

2. Missing Sample Order Verification

In tools like DESeq2, the column names of the count matrix MUST match the row names of the metadata in the exact same order. Instruct the agent to add: assert all(counts.columns == metadata.index).

⚠️

3. Ingesting Multi-Gigabyte Data Tables

If the agent opens a 2GB raw file, it will choke your token rate limits. Keep raw data in a folder listed in .gitignore and let the agent interact with it strictly via terminal commands.

⚠️

4. Hallucinated Gene Identifiers

Never ask the AI to "guess missing gene symbols." Require it to join against the provided gene_annotations.tsv or use standard Ensembl/NCBI mappings.

💡 Teaching Goal: Reinforce that AI does not replace scientific understanding. Students are responsible for verifying that the statistical model matches the experimental biology.
